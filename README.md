# تن‌یار — وب‌اپلیکیشن رزرو و مدیریت ماساژ درمانی

این نسخه از حالت صرفاً فرانت‌اند خارج شده و رزروها را روی سرور نگه می‌دارد. مشتری‌ها هرگز API لیست کل نوبت‌ها یا یادداشت‌های درمانگر را دریافت نمی‌کنند.

## امکانات
- رزرو آنلاین با کنترل ظرفیت و جلوگیری از دوباره‌رزرو شدن یک ساعت
- ساعات کاری قابل تنظیم توسط ادمین
- خدمات با مدت و قیمت قابل ویرایش
- وضعیت نوبت: در انتظار تأیید، تأیید شده، انجام شد، لغو شد
- داشبورد ادمین و شمارنده نوبت‌های جدید/در انتظار
- پروفایل مشتری، یادداشت‌های درمانگر و تاریخچه جلسات
- باشگاه وفاداری بر اساس جلسات انجام‌شده
- پیگیری رزرو مشتری با شماره تماس + کد رزرو
- ذخیره اطلاعات در `data/db.json` سمت سرور
- احراز هویت ادمین با Session Token
- UI راست‌چین، مینیمال و بدون glassmorphism

## اجرا
نیاز به Node.js 18+ دارد.

```bash
npm install
npm start
```
سپس `http://localhost:3000` را باز کنید.

## ورود ادمین
مقادیر پیش‌فرض برای دمو:
- username: `admin`
- password: `change-this-password`

برای استفاده واقعی، متغیرهای محیطی `ADMIN_USERNAME` و `ADMIN_PASSWORD` را تغییر دهید. در محیط production حتماً HTTPS، رمز قوی، محدودسازی درخواست‌ها و دیتابیس واقعی (PostgreSQL/MySQL) اضافه شود.

## عکس‌ها و فونت
URL عکس‌ها در `data/db.json` و `index.html` مشخص هستند و می‌توان آنها را با عکس‌های واقعی خودتان جایگزین کرد.
فونت اصلی از طریق `--font-main` در `css/styles.css` قابل تعویض است. برای فونت محلی می‌توان `@font-face` را اضافه کرد و فقط مقدار همان متغیر را تغییر داد.
